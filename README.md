# Floating-Lyrics-Player
A lightweight, minimalist floating lyrics player. 一款轻量级、极简的悬浮歌词播放器。

![](https://raz1ner.com/post-images/1768190006252.png)

# Development
To get started just pull the repo and run the following

```Shell
npm install
npm start

# package
rm -rf dist && npm run dist
```
